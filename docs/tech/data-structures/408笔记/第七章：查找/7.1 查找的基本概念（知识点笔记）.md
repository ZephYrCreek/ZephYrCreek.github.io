# 7.1 查找的基本概念（知识点笔记）

## 1. 查找

**定义：** 在数据集合中寻找满足某种条件的数据元素的过程。

- **查找成功：** 找到满足条件的数据元素。
- **查找失败：** 数据集合中不存在满足条件的数据元素。

## 2. 查找表

**定义：** 用于查找的数据集合，由同一类型的数据元素或记录组成。

常见操作：

- 查询特定数据元素；
- 检索数据元素的属性；
- 插入数据元素；
- 删除数据元素。

## 3. 静态查找表与动态查找表

| 类型 | 操作特征 |
| --- | --- |
| 静态查找表 | 只进行查询，不涉及插入、删除 |
| 动态查找表 | 除查询外，还需要插入或删除元素 |

::: warning
区分依据是查找表需要支持的操作，不是内存分配方式。
:::

## 4. 关键字

**定义：** 数据元素中能够唯一标识该元素的某个数据项的值。

关系：

```text
数据元素：完整记录
数据项：记录中的字段
关键字：用于标识、查找记录的数据项的值
```

## 5. 查找长度

**定义：** 一次查找过程中进行的关键字比较次数。

不等同于：

- 程序语句执行次数；
- 内存访问次数。

## 6. 平均查找长度

**平均查找长度（Average Search Length，ASL）：** 各种查找情况下，关键字比较次数的加权平均值。

$$
\boxed{\mathrm{ASL}=\sum_{i=1}^{n}P_iC_i}
$$

其中：

- $n$：查找表中的数据元素个数；
- $P_i$：查找第 $i$ 个数据元素的概率；
- $C_i$：找到第 $i$ 个数据元素所需的关键字比较次数。

### 等概率情况

若：

$$
P_i=\frac{1}{n}
$$

则：

$$
\boxed{\mathrm{ASL}=\frac{1}{n}\sum_{i=1}^{n}C_i}
$$

即对各元素的比较次数求算术平均。

### 非等概率情况

必须使用 $P_i$ 加权，不能直接对 $C_i$ 求算术平均。

## 7. 易错点

1. ASL 衡量的是平均关键字比较次数，不是时间复杂度本身。
2. 计算 ASL 前应明确成功查找或失败查找的概率及比较次数。
3. 不同查找算法作用于同一张表时，ASL 仍可能不同。
4. “静态查找表”不等于采用静态内存分配的表。
5. 关键字是用于标识数据元素的数据项的值，不是完整的数据元素。
