# 6.3 图的遍历

::: info 核心思想
图的遍历是从某个顶点出发，沿图中的边访问顶点，并使每个顶点只被访问一次。

- **BFS（广度优先搜索）**：由近及远、逐层扩展，使用队列。
- **DFS（深度优先搜索）**：一条路尽可能走到底，再回溯，使用递归调用栈或显式栈。
- 图可能有环，因此二者都必须使用 `visited[]` 防止重复访问。
:::

---

## 6.3.0 图遍历的共同基础

### 1. 为什么图遍历需要 `visited[]`

树中不存在环，而图中可能存在：

```text
A — B
 \ /
  C
```

若不记录访问状态，可能出现：

```text
A → B → C → A → B → C → ...
```

因此需要访问标记数组：

```c
bool visited[MaxVertexNum];
```

其中：

```c
visited[v] == false  // 顶点 v 尚未访问
visited[v] == true   // 顶点 v 已经访问
```

本质是：

$$
\boxed{\text{用状态标记避免重复访问和死循环}}
$$

---

### 2. 一次搜索不一定能遍历整个图

从顶点 $v$ 开始的一次 BFS 或 DFS，只能访问：

$$
\boxed{\text{从 }v\text{ 可达的全部顶点}}
$$

例如非连通无向图：

```text
0 — 1 — 2      3 — 4
```

从 0 出发只能访问 $0,1,2$，无法到达 $3,4$。

若要遍历整个图，需要使用外层循环：

```c
for (int i = 0; i < G.vexnum; i++) {
    if (!visited[i]) {
        Search(G, i);   // BFS 或 DFS
    }
}
```

::: warning
对无向图而言，外层遍历每重新启动一次 BFS/DFS，就发现一个新的连通分量。
:::

---

### 3. 邻接点的访问顺序会影响遍历序列

同一个图的 BFS、DFS 序列通常不唯一，因为它们取决于：

- 起始顶点；
- 邻接点的存储与扫描顺序。

邻接矩阵通常按顶点编号递增扫描；邻接表的次序可能受输入顺序、头插法或尾插法影响。

---

## 6.3.1 广度优先搜索 BFS

### 1. 基本思想

BFS：

$$
\boxed{\text{Breadth-First Search，广度优先搜索}}
$$

它类似于树的：

$$
\boxed{\text{层序遍历}}
$$

搜索特点：

$$
\boxed{\text{由近及远，一层一层向外扩展}}
$$

例如：

```text
          A
       /  |  \
      B   C   D
     / \      |
    E   F     G
```

从 A 开始，按图示顺序进行 BFS：

```text
第 0 层：A
第 1 层：B C D
第 2 层：E F G
```

访问序列：

$$
\boxed{A,B,C,D,E,F,G}
$$

---

### 2. 为什么 BFS 使用队列

队列具有：

$$
\boxed{\text{先进先出 FIFO}}
$$

访问 A 后发现 B、C、D：

```text
队头 → B C D ← 队尾
```

取出 B，若 B 又发现 E、F，则将它们放到队尾：

```text
队头 → C D E F ← 队尾
```

因此，虽然 E、F 已经被发现，但仍要先扩展同层的 C、D。

$$
\boxed{\text{FIFO 保证先扩展近处顶点，再扩展远处顶点}}
$$

队列中的顶点表示：

> **已经被发现并标记，但其邻接点尚未全部检查的顶点。**

---

### 3. BFS 的五个核心步骤

```text
① 访问起点
      ↓
② 标记起点已访问
      ↓
③ 起点入队
      ↓
④ 队头顶点出队并扩展
      ↓
⑤ 未访问邻接点：访问、标记、入队
      ↓
重复④⑤，直到队空
```

---

### 4. 抽象存储结构下的 BFS

沿用 [6.2 图的存储及基本操作](./6.2%20%E5%9B%BE%E7%9A%84%E5%AD%98%E5%82%A8%E5%8F%8A%E5%9F%BA%E6%9C%AC%E6%93%8D%E4%BD%9C.md) 中的：

- `FirstNeighbor(G, v)`：取得第一个邻接点；
- `NextNeighbor(G, v, w)`：取得 `w` 后的下一个邻接点。

```c
bool visited[MaxVertexNum];
SqQueue Q;

void BFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    EnQueue(&Q, v);

    while (!QueueEmpty(Q)) {
        DeQueue(&Q, &v);

        for (int w = FirstNeighbor(G, v);
             w != -1;
             w = NextNeighbor(G, v, w)) {

            if (!visited[w]) {
                visit(w);
                visited[w] = true;
                EnQueue(&Q, w);
            }
        }
    }
}
```

::: warning 发现时立即标记
必须在邻接点 `w` **入队时**执行：

```c
visited[w] = true;
```

不能等到 `w` 出队时再标记，否则多个顶点可能在此之前重复发现 `w`，导致 `w` 重复入队。
:::

---

### 5. `BFSTraverse()`：遍历整个图

```c
void BFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++) {
        visited[i] = false;
    }

    InitQueue(&Q);

    for (int i = 0; i < G.vexnum; i++) {
        if (!visited[i]) {
            BFS(G, i);
        }
    }
}
```

两个函数的职责不同：

| 函数 | 作用 |
|---|---|
| `BFS(G, v)` | 访问从 $v$ 可达的全部顶点 |
| `BFSTraverse(G)` | 借助外层循环遍历整个图 |

一次 `BFS()` 结束时队列必然为空，所以整个 `BFSTraverse()` 中只需初始化一次队列。

---

### 6. 邻接矩阵实现 BFS

邻接矩阵需要扫描当前顶点对应的整行：

```c
void BFS_MGraph(MGraph G, int v) {
    visit(G.Vex[v]);
    visited[v] = true;
    EnQueue(&Q, v);

    while (!QueueEmpty(Q)) {
        DeQueue(&Q, &v);

        for (int w = 0; w < G.vexnum; w++) {
            if (G.Edge[v][w] != 0 && !visited[w]) {
                visit(G.Vex[w]);
                visited[w] = true;
                EnQueue(&Q, w);
            }
        }
    }
}
```

核心是：

```c
for (int w = 0; w < G.vexnum; w++)
```

即依次检查：

$$
Edge[v][0],Edge[v][1],\ldots,Edge[v][n-1]
$$

::: warning
`G.Edge[v][w] != 0` 只适用于“0 表示无边”的编码。

若带权图允许零权边，必须另设邻接标记或使用明确的“无边”哨兵值。
:::

---

### 7. 邻接表实现 BFS

邻接表中存储的本来就是真实存在的邻接点，因此只需沿边表遍历：

```c
void BFS_ALGraph(ALGraph G, int v) {
    visit(G.vertices[v].data);
    visited[v] = true;
    EnQueue(&Q, v);

    while (!QueueEmpty(Q)) {
        DeQueue(&Q, &v);

        ArcNode *p = G.vertices[v].firstarc;
        while (p != NULL) {
            int w = p->adjvex;

            if (!visited[w]) {
                visit(G.vertices[w].data);
                visited[w] = true;
                EnQueue(&Q, w);
            }

            p = p->nextarc;
        }
    }
}
```

这里不需要再判断 `v` 和 `w` 之间是否有边，因为：

$$
\boxed{\text{边表结点中存储的本来就是 }v\text{ 的邻接点}}
$$

---

### 8. 两种存储结构下的实现差异

`BFSTraverse()` 的整体逻辑不变，主要差异集中在 `BFS()` 中如何枚举邻接点。

| 存储结构 | 枚举 $v$ 的邻接点 |
|---|---|
| 邻接矩阵 | 扫描第 $v$ 行的所有 $|V|$ 个位置 |
| 邻接表 | 遍历 `vertices[v]` 的边表 |

即：

```text
邻接矩阵：检查所有候选顶点是否与 v 相邻
邻接表：直接遍历真正与 v 相邻的顶点
```

---

### 9. BFS 的复杂度

设：

$$
n=|V|,\qquad e=|E|
$$

#### 邻接矩阵

每个顶点至多出队一次，每次都扫描矩阵的一整行：

$$
\boxed{O(|V|^2)}
$$

#### 邻接表

- 每个顶点访问一次：$O(|V|)$；
- 所有边表结点总共扫描一次。

无向图中每条边存两次，扫描量为 $2|E|$；有向图的出边邻接表中每条弧存一次，扫描量为 $|E|$。

因此：

$$
O(|V|+2|E|)=\boxed{O(|V|+|E|)}
$$

#### 辅助空间

`visited[]` 和队列最多需要与顶点数同阶的空间：

$$
\boxed{O(|V|)}
$$

---

### 10. BFS 求无权图的单源最短路径

#### 基本结论

在无权图中，路径长度按经过的边数计算。

BFS 按距离起点由近到远的顺序发现顶点，因此：

$$
\boxed{\text{BFS 第 }k\text{ 层顶点到起点的最短距离为 }k}
$$

并且：

$$
\boxed{\text{顶点第一次被 BFS 发现时，得到的距离就是最短距离}}
$$

#### 距离数组

```c
int d[MaxVertexNum];
```

- `d[s] = 0`：起点到自身距离为 0；
- `d[v] = -1`：尚未发现或不可达；
- 从 `u` 首次发现 `w` 时：

$$
\boxed{d[w]=d[u]+1}
$$

#### 算法

```c
void BFS_MIN_Distance(Graph G, int s) {
    for (int i = 0; i < G.vexnum; i++) {
        visited[i] = false;
        d[i] = -1;
    }

    InitQueue(&Q);
    visited[s] = true;
    d[s] = 0;
    EnQueue(&Q, s);

    while (!QueueEmpty(Q)) {
        int u;
        DeQueue(&Q, &u);

        for (int w = FirstNeighbor(G, u);
             w != -1;
             w = NextNeighbor(G, u, w)) {

            if (!visited[w]) {
                visited[w] = true;
                d[w] = d[u] + 1;
                EnQueue(&Q, w);
            }
        }
    }
}
```

::: warning
普通 BFS 只保证求出：

- 无权图的最短路径；
- 或所有边具有相同正权值时的最短路径。

对一般带权图，不能直接使用普通 BFS。
:::

若还要输出具体路径，可增加前驱数组：

```c
parent[w] = u;
```

它表示 `w` 第一次由 `u` 发现。

---

### 11. 广度优先生成树与生成森林

#### BFS 生成树

在连通无向图中，从某个顶点开始 BFS，并保留：

$$
\boxed{\text{每个新顶点第一次被发现时所经过的边}}
$$

得到一棵广度优先生成树。

可用 `parent[]` 记录：

```c
if (!visited[w]) {
    visited[w] = true;
    parent[w] = v;
    EnQueue(&Q, w);
}
```

若原图有 $n$ 个顶点，则 BFS 生成树：

- 包含全部 $n$ 个顶点；
- 恰有 $n-1$ 条树边；
- 不含环；
- 根到任意顶点的树路径，是原图中的一条最短路径。

::: warning
BFS 生成树不一定唯一，起点或邻接点访问顺序不同，都可能得到不同的树。
:::

#### BFS 生成森林

若无向图不连通，每个连通分量分别得到一棵 BFS 生成树，合称：

$$
\boxed{\text{广度优先生成森林}}
$$

若图有 $n$ 个顶点、$k$ 个连通分量，则：

$$
\boxed{\text{森林中有 }k\text{ 棵树，树边总数为 }n-k}
$$

## 6.3.2 深度优先搜索 DFS

### 1. 基本思想

DFS：

$$
\boxed{\text{Depth-First Search，深度优先搜索}}
$$

搜索策略：

$$
\boxed{\text{沿一条路径尽可能深入，无法继续时再回溯}}
$$

例如：

```text
          A
        /   \
       B     C
      / \   / \
     D   E F   G
```

按从左到右的邻接顺序，DFS 序列为：

$$
\boxed{A,B,D,E,C,F,G}
$$

过程可以理解为：

```text
A → B → D
        ↓ 无路可走，回溯到 B
      B → E
        ↓ 无路可走，回溯到 A
      A → C → F → 回溯 → G
```

回溯不等于重新访问，因此回溯时不会再次执行 `visit()`。

---

### 2. 为什么递归适合实现 DFS

DFS 的逻辑可以概括为：

```c
void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;

    for (v 的每个邻接点 w) {
        if (!visited[w]) {
            DFS(G, w);
        }
    }
}
```

当 `DFS(G, v)` 调用 `DFS(G, w)` 时：

- 当前函数暂停；
- 系统调用栈保存当前执行位置和局部状态；
- `DFS(G, w)` 结束后返回原调用位置；
- 继续检查 `v` 的其他邻接点。

因此：

$$
\boxed{\text{函数调用栈自动实现了 DFS 的深入与回溯}}
$$

DFS 也可用显式栈非递归实现，但邻接点的入栈次序会影响最终访问顺序。

---

### 3. 抽象存储结构下的 DFS

```c
void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;

    for (int w = FirstNeighbor(G, v);
         w != -1;
         w = NextNeighbor(G, v, w)) {

        if (!visited[w]) {
            DFS(G, w);
        }
    }
}
```

DFS 与 BFS 的关键区别：

```c
// BFS：先排队，以后再扩展
EnQueue(&Q, w);

// DFS：立即深入
DFS(G, w);
```

---

### 4. `DFSTraverse()`：遍历整个图

```c
void DFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++) {
        visited[i] = false;
    }

    for (int i = 0; i < G.vexnum; i++) {
        if (!visited[i]) {
            DFS(G, i);
        }
    }
}
```

与 `BFSTraverse()` 相比：

- 都要初始化 `visited[]`；
- 都要用外层循环处理非连通图；
- DFS 不需要初始化队列；
- 递归 DFS 实际使用的是系统调用栈。

---

### 5. 邻接矩阵实现 DFS

```c
void DFS_MGraph(MGraph G, int v) {
    visit(G.Vex[v]);
    visited[v] = true;

    for (int w = 0; w < G.vexnum; w++) {
        if (G.Edge[v][w] != 0 && !visited[w]) {
            DFS_MGraph(G, w);
        }
    }
}
```

需要扫描第 $v$ 行的全部位置，才能找到所有邻接点。

---

### 6. 邻接表实现 DFS

```c
void DFS_ALGraph(ALGraph G, int v) {
    visit(G.vertices[v].data);
    visited[v] = true;

    ArcNode *p = G.vertices[v].firstarc;

    while (p != NULL) {
        int w = p->adjvex;

        if (!visited[w]) {
            DFS_ALGraph(G, w);
        }

        p = p->nextarc;
    }
}
```

与 BFS 一样，邻接矩阵和邻接表版本的主要区别仍是：

$$
\boxed{\text{如何找到当前顶点的邻接点}}
$$

---

### 7. DFS 的复杂度

#### 邻接矩阵

每访问一个顶点，都要扫描邻接矩阵的一整行：

$$
\boxed{O(|V|^2)}
$$

#### 邻接表

每个顶点访问一次，所有边表结点总共扫描一次：

$$
\boxed{O(|V|+|E|)}
$$

#### 辅助空间

递归栈深度取决于搜索路径的最大深度 $h$：

$$
O(h),\qquad 1\le h\le |V|
$$

链状图中递归深度可达到 $|V|$，因此最坏辅助空间复杂度为：

$$
\boxed{O(|V|)}
$$

若计入 `visited[]`，总体辅助空间仍为 $O(|V|)$。

---

### 8. 深度优先生成树与生成森林

#### DFS 生成树

在连通无向图中，保留 DFS 每次首次发现新顶点时经过的边，可得到：

$$
\boxed{\text{深度优先生成树}}
$$

若从 `v` 首次进入 `w`：

```c
if (!visited[w]) {
    parent[w] = v;
    DFS(G, w);
}
```

DFS 生成树具有：

- 包含全部顶点；
- 恰有 $n-1$ 条边；
- 不含环；
- 形态可能较深；
- 不保证根到各顶点的树路径是原图最短路径；
- 不一定唯一。

#### DFS 生成森林

若无向图不连通，每个连通分量分别生成一棵 DFS 树，合称：

$$
\boxed{\text{深度优先生成森林}}
$$

若有 $n$ 个顶点、$k$ 个连通分量，则：

$$
\boxed{\text{森林有 }k\text{ 棵树，共 }n-k\text{ 条树边}}
$$

## 6.3.3 图的遍历与连通性

### 1. 无向图

对非空无向图任选一个顶点 $v$：

$$
\boxed{
G\text{ 连通}
\iff
\text{从 }v\text{ 出发的一次 BFS/DFS 能访问全部顶点}
}
$$

因为无向边可以双向行走，从 $v$ 能到达全部顶点，就能推出任意两个顶点之间存在路径。

对于无向图：

$$
\boxed{
\text{外层遍历直接启动 BFS/DFS 的次数}
=
\text{连通分量数}
}
$$

这里统计的是 `BFSTraverse()` 或 `DFSTraverse()` 在外层直接发起搜索的次数，**不包括 DFS 内部的递归调用**。

---

### 2. 判断无向图是否连通

应当只从一个顶点执行**一次** BFS/DFS，再检查所有顶点是否都已访问。

```c
bool IsConnected(Graph G) {
    if (G.vexnum == 0) {
        return true;   // 按具体题目对空图的约定处理
    }

    for (int i = 0; i < G.vexnum; i++) {
        visited[i] = false;
    }

    BFS(G, 0);        // 也可使用 DFS(G, 0)

    for (int i = 0; i < G.vexnum; i++) {
        if (!visited[i]) {
            return false;
        }
    }

    return true;
}
```

::: warning
不能先执行完整的 `BFSTraverse()` 或 `DFSTraverse()` 再检查 `visited[]`。

因为外层遍历会从所有尚未访问的顶点重新启动搜索，无论图是否连通，最终所有 `visited[i]` 都会变成 `true`。
:::

---

### 3. 有向图

强连通要求任意两个顶点都能相互到达：

$$
u\leadsto v,\qquad v\leadsto u
$$

有向图中：

$$
\boxed{
\text{从某个顶点一次遍历能访问全部顶点}
\not\Rightarrow
\text{图强连通}
}
$$

反例：

```text
A → B → C
```

从 A 出发可访问全部顶点，但 C 无法回到 A，因此该图不是强连通图。

正确结论是：

$$
\boxed{
G\text{ 强连通}
\iff
\text{从每个顶点出发都能访问全部顶点}
}
$$

并且，一次有向图遍历得到的是：

$$
\boxed{\text{起点的可达顶点集合}}
$$

不一定是强连通分量。

因此，有向图遍历森林的树数不一定等于强连通分量数。

## BFS 与 DFS 对比

| 对比项 | BFS | DFS |
|---|---|---|
| 中文 | 广度优先搜索 | 深度优先搜索 |
| 搜索策略 | 由近及远、逐层扩展 | 尽可能深入、无法继续再回溯 |
| 类似的树遍历 | 层序遍历 | 先序式深入 |
| 主要辅助结构 | 队列 | 递归调用栈或显式栈 |
| 发现新顶点后 | 标记并入队 | 标记并立即递归深入 |
| 防止重复访问 | `visited[]` | `visited[]` |
| 邻接矩阵时间 | $O(V^2)$ | $O(V^2)$ |
| 邻接表时间 | $O(V+E)$ | $O(V+E)$ |
| 最坏辅助空间 | $O(V)$ | $O(V)$ |
| 无权图单源最短路径 | **可以** | 不保证 |
| 生成树根到顶点路径 | 是最短路径 | 不一定是最短路径 |
| 遍历序列是否唯一 | 不一定 | 不一定 |

## 生成树与生成森林对比

| 对比项 | BFS 生成树 | DFS 生成树 |
|---|---|---|
| 树边选取 | 首次发现新顶点时的边 | 首次发现新顶点时的边 |
| 常见形态 | 按距离分层 | 可能形成较深路径 |
| 根到各顶点的路径 | 原图中的最短路径 | 不一定最短 |
| 是否一定唯一 | 否 | 否 |
| 连通图的树边数 | $n-1$ | $n-1$ |
| $k$ 个连通分量时 | $k$ 棵树、$n-k$ 条边 | $k$ 棵树、$n-k$ 条边 |

::: warning
BFS/DFS 生成树都不是最小生成树（MST）。

- BFS 生成树关注从根出发的层次与最短边数；
- DFS 生成树反映深入与回溯过程；
- 最小生成树关注树中所有边的权值总和最小。
:::

# 6.3 高频考点

::: warning 必掌握
1. 图可能有环，所以 BFS、DFS 都需要 `visited[]`。
2. 一次 BFS/DFS 只访问从起点可达的顶点；遍历整个非连通图需要外层循环。
3. BFS 使用队列，DFS 使用递归调用栈或显式栈。
4. BFS 必须在顶点**入队时**立即设置 `visited = true`。
5. 每个顶点在标准 BFS 中最多入队一次、出队一次。
6. 邻接矩阵 BFS/DFS：$O(V^2)$；邻接表 BFS/DFS：$O(V+E)$。
7. BFS 可以求无权图单源最短路径，首次发现顶点时距离最短。
8. BFS 生成树中根到任意顶点的路径是最短路径；DFS 不保证。
9. 无向图中，外层直接启动搜索的次数等于连通分量数。
10. 有向图中，一次搜索访问到的是可达集合，不一定是强连通分量。
:::

# 408 易错点

### 1. “访问”与“扩展”不是同一时刻

BFS 中顶点入队前已经完成访问和标记；出队表示现在开始扫描它的邻接点。

```text
发现顶点 → 访问并标记 → 入队 → 以后出队扩展
```

---

### 2. BFS 的外层 `for` 不能代替队列

外层循环只负责处理非连通图，队列才负责保证同一棵搜索树中按层次扩展。

---

### 3. 无环不代表可以省略 `visited[]`

有向无环图中，同一顶点也可能通过多条不同路径到达：

```text
  B
 / \
A   D
 \ /
  C
```

若不标记，D 仍可能被重复访问。

---

### 4. BFS/DFS 序列不一定唯一

遍历序列受起点和邻接点次序影响。题目若给出邻接矩阵，通常按编号递增扫描；若给出邻接表，应严格按链表顺序扫描。

---

### 5. 有向图不能直接套用无向图的连通结论

```text
A → B → C
```

从 A 一次遍历可访问所有顶点，但图不强连通。

---

### 6. DFS 的空间复杂度看最大递归深度

递归调用总次数可能很多，但同一时刻占用栈空间的是尚未返回的调用链。最坏情况下链长为 $|V|$，所以是 $O(|V|)$。

---

# 一句话速记

```text
BFS：队列，先进先出，一圈一圈扩散，可求无权最短路。
DFS：栈，沿路深入，走不动就回溯，不保证最短路。
```

$$
\boxed{
\begin{aligned}
\text{邻接矩阵遍历} &:\ O(V^2)\\
\text{邻接表遍历} &:\ O(V+E)\\
\text{辅助空间} &:\ O(V)
\end{aligned}
}
$$

对于有 $n$ 个顶点、$k$ 个连通分量的无向图：

$$
\boxed{
\text{生成森林有 }k\text{ 棵树，共 }n-k\text{ 条树边}
}
$$
