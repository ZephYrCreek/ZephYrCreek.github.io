# 链队列：带头结点与不带头结点代码对比

## 1. 公共结构定义

```cpp
typedef int ElemType;

typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct {
    LinkNode *front;
    LinkNode *rear;
} LinkQueue;
```

## 2. 核心区别

| 对比项 | 带头结点 | 不带头结点 |
|---|---|---|
| `front` 指向 | 头结点 | 第一个数据结点 |
| `rear` 指向 | 最后一个数据结点 | 最后一个数据结点 |
| 空队列状态 | `front == rear`，二者指向头结点 | `front == rear == nullptr` |
| 第一个数据结点 | `front->next` | `front` |
| 一个元素时 | `front != rear` | `front == rear` |
| 空队列入队 | 不需要特殊处理 | 需要特殊处理 |
| 最后一个元素出队 | `rear = front` | `front = rear = nullptr` |

## 3. 初始化

| 带头结点 | 不带头结点 |
|---|---|
| 创建一个不存放有效数据的头结点 | 不创建任何结点 |
| <pre><code>void initQueueWithHead(LinkQueue &Q) {<br>    Q.front = Q.rear = new LinkNode;<br>    Q.front->next = nullptr;<br>}</code></pre> | <pre><code>void initQueueWithoutHead(LinkQueue &Q) {<br>    Q.front = Q.rear = nullptr;<br>}</code></pre> |

## 4. 判断队空

| 带头结点 | 不带头结点 |
|---|---|
| `front`、`rear` 都指向头结点时为空 | `front` 指向空时为空 |
| <pre><code>bool isEmptyWithHead(const LinkQueue &Q) {<br>    return Q.front == Q.rear;<br>}</code></pre> | <pre><code>bool isEmptyWithoutHead(const LinkQueue &Q) {<br>    return Q.front == nullptr;<br>}</code></pre> |

::: warning 易错点
- `rear->next == nullptr` 不能判断队空，因为非空队列的最后一个结点也满足该条件。
- 不带头结点时，`front == rear` 不能判断队空，因为队列只有一个元素时二者也相等。
:::

## 5. 入队

| 带头结点 | 不带头结点 |
|---|---|
| 空队列中 `rear` 仍指向有效的头结点，可以直接连接新结点 | 空队列中 `rear == nullptr`，第一次入队必须单独处理 |
| <pre><code>void enQueueWithHead(LinkQueue &Q, ElemType x) {<br>    LinkNode *s = new LinkNode;<br>    s->data = x;<br>    s->next = nullptr;<br><br>    Q.rear->next = s;<br>    Q.rear = s;<br>}</code></pre> | <pre><code>void enQueueWithoutHead(LinkQueue &Q, ElemType x) {<br>    LinkNode *s = new LinkNode;<br>    s->data = x;<br>    s->next = nullptr;<br><br>    if (Q.front == nullptr) {<br>        Q.front = Q.rear = s;<br>    }<br>    else {<br>        Q.rear->next = s;<br>        Q.rear = s;<br>    }<br>}</code></pre> |

## 6. 出队

| 带头结点 | 不带头结点 |
|---|---|
| 删除的是 `front->next` | 删除的是 `front` |
| 删除最后一个数据结点后，头结点仍然保留 | 删除最后一个结点后，队列中不再有任何结点 |
| <pre><code>bool deQueueWithHead(LinkQueue &Q, ElemType &x) {<br>    if (Q.front == Q.rear) {<br>        return false;<br>    }<br><br>    LinkNode *p = Q.front->next;<br>    x = p->data;<br><br>    Q.front->next = p->next;<br><br>    if (p == Q.rear) {<br>        Q.rear = Q.front;<br>    }<br><br>    delete p;<br>    return true;<br>}</code></pre> | <pre><code>bool deQueueWithoutHead(LinkQueue &Q, ElemType &x) {<br>    if (Q.front == nullptr) {<br>        return false;<br>    }<br><br>    LinkNode *p = Q.front;<br>    x = p->data;<br><br>    if (Q.front == Q.rear) {<br>        Q.front = Q.rear = nullptr;<br>    }<br>    else {<br>        Q.front = p->next;<br>    }<br><br>    delete p;<br>    return true;<br>}</code></pre> |

## 7. 读取队头元素

| 带头结点 | 不带头结点 |
|---|---|
| 队头元素位于 `front->next` | 队头元素位于 `front` |
| <pre><code>bool getHeadWithHead(const LinkQueue &Q, ElemType &x) {<br>    if (Q.front == Q.rear) {<br>        return false;<br>    }<br><br>    x = Q.front->next->data;<br>    return true;<br>}</code></pre> | <pre><code>bool getHeadWithoutHead(const LinkQueue &Q, ElemType &x) {<br>    if (Q.front == nullptr) {<br>        return false;<br>    }<br><br>    x = Q.front->data;<br>    return true;<br>}</code></pre> |

::: warning
读取队头元素只读取数据，不能移动 `front`，也不能释放结点。
:::

## 8. 销毁队列

| 带头结点 | 不带头结点 |
|---|---|
| 先删除所有数据结点，最后删除头结点 | 依次删除所有数据结点 |
| <pre><code>void destroyQueueWithHead(LinkQueue &Q) {<br>    while (Q.front->next != nullptr) {<br>        LinkNode *p = Q.front->next;<br>        Q.front->next = p->next;<br>        delete p;<br>    }<br><br>    delete Q.front;<br>    Q.front = Q.rear = nullptr;<br>}</code></pre> | <pre><code>void destroyQueueWithoutHead(LinkQueue &Q) {<br>    while (Q.front != nullptr) {<br>        LinkNode *p = Q.front;<br>        Q.front = p->next;<br>        delete p;<br>    }<br><br>    Q.rear = nullptr;<br>}</code></pre> |

## 9. 操作复杂度

| 操作 | 带头结点 | 不带头结点 |
|---|---:|---:|
| 初始化 | $O(1)$ | $O(1)$ |
| 判断队空 | $O(1)$ | $O(1)$ |
| 入队 | $O(1)$ | $O(1)$ |
| 出队 | $O(1)$ | $O(1)$ |
| 读取队头 | $O(1)$ | $O(1)$ |
| 销毁队列 | $O(n)$ | $O(n)$ |

## 10. 核心代码记忆表

| 操作        | 带头结点                          | 不带头结点                    |
| --------- | ----------------------------- | ------------------------ |
| 初始化       | `front = rear = new LinkNode` | `front = rear = nullptr` |
| 判空        | `front == rear`               | `front == nullptr`       |
| 第一个数据结点   | `front->next`                 | `front`                  |
| 读取队头      | `front->next->data`           | `front->data`            |
| 空队列第一次入队  | 不需要特殊处理                       | `front = rear = s`       |
| 删除的结点     | `p = front->next`             | `p = front`              |
| 删除最后一个元素后 | `rear = front`                | `front = rear = nullptr` |

::: info 根本区别
带头结点时，`front` 始终指向头结点，所以空队列中仍然存在一个可操作的结点，入队代码更加统一。

不带头结点时，`front` 直接指向第一个数据结点。空队列没有任何结点，因此第一次入队和最后一次出队都必须单独处理。
:::
